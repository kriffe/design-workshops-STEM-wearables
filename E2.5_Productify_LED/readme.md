# Design Workshop

Easiest way to producity a a all in one circuit board is to just attach a string to it to make it a necklace, and tape or fold cardboard patterns to include the batteries.

Microbit v2 kit from BBC comes with has a brilliantly simple cardboard to fold to get the battery to sit together with the board.
